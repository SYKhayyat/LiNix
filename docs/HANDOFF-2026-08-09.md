## Things worth knowing before you touch these files

- **`tests/main.rs` is the suite.** `autotests = false`; a new `tests/*.rs` does not run until
  it is a `mod` there, and `every_test_file_is_in_the_suite` fails when the two disagree.
- **Four gates fire on any new subcommand**, and answering them is the work, not a formality:
  the data-lock reader list in `src/main.rs`, `dry_run_every_verb_tests`'s exemption table (with
  a reason), the `--help` map in `src/cli/args.rs`, and `unknown_backend_family_tests`. All four
  caught `adapters` and all four were answered.
- **`app::adapters::SURFACES` is the definition of an extension surface.** A ninth reader that
  calls `layout.adapter_file("thing")` without a row there fails
  `every_adapter_surface_is_in_the_table`. Do not build a list of surfaces from the `Layout`
  accessors — that is how `firewall:` was invisible.
- **`grader_gate_parity_tests` already does gate parity.** I wrote a second implementation
  during compaction G before noticing, and deleted it. Look for the existing gate first; this
  repo's whole problem is two of everything.
- **The register drifts silently.** `decision-count.sh --check` is real and it caught
  `decisions.md` and `SPEC.md` both four short, four days after the ruling. Run it after any
  session that answers a decision.
- **CRLF.** Most of `src/` is CRLF in the working tree. A Python heredoc doing `.replace()` with
  `\n` matches nothing and reports success. Use the Edit tool, or read with `newline=""` and
  substitute the file's own ending.
